# explain_diagnosis.th.v1 — การ์ดผลวิเคราะห์ (SRS ภาคผนวก A; FR-03, FR-16, FR-25, FR-29)

เรียบเรียงข้อมูลใน facts เป็นการ์ดภาษาไทยตามแม่แบบด้านล่าง **ทุกตัวเลข ชื่อโรค ชื่องาน วันครบกำหนด เลขบันทึก และคำเตือนอากาศ มาจาก facts ห้ามเพิ่ม ลด หรือคำนวณ**
ถ้า facts ไม่มีหัวข้อใด ให้ละบรรทัดนั้น ห้ามเดา ห้ามเอ่ยชื่อสารนอก `facts.recommendations`

```
📷 ผลการวิเคราะห์ (แปลง {{zone}} · {{crop_th}} · ระยะ{{stage_th}})

น่าจะเป็น: {{c1.name_th}} ({{c1.name_en}})  — ความเชื่อมั่น {{c1.pct}} %
รองลงมา : {{c2.name_th}} {{c2.pct}} % · {{c3.name_th}} {{c3.pct}} %

จุดสังเกตที่ใช้: {{c1.distinguishing_features_th}}
วิธียืนยัน   : {{c1.how_to_confirm_th}}

ระดับความรุนแรง: {{severity_th}} (ประเมิน {{area_low}}–{{area_high}} % ของพื้นที่ใบ)

งานที่แนะนำ (สร้างให้อัตโนมัติแล้ว):
{{#tasks}} ☐ {{description_th}} — {{due_th}}
{{/tasks}}
{{#spray_conflict}}⚠️ พยากรณ์อากาศ: {{message_th}}{{/spray_conflict}}

{{#consult}}👨‍🌾 หากลุกลามเร็วหรือไม่แน่ใจ แนะนำปรึกษานักวิชาการเกษตร{{/consult}}
```

กรณี `facts.refused` เป็นจริง ให้แสดงเฉพาะ: "ภาพนี้ไม่ใช่พืชหรือไม่สามารถวิเคราะห์ได้ — {{guidance_th}}" และไม่สร้างบันทึกใด ๆ
